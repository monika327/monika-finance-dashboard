# 💰 Monika Finance Dashboard

A simple and clean finance dashboard built using React + Vite.

## 🚀 Features
- Track income and expenses
- Calculate total balance automatically
- Simple and user-friendly UI
- Category-based transactions

## 🛠️ Tech Stack
- React.js
- Vite
- JavaScript
- CSS

## 📦 Installation

```bash
npm install
npm run dev
